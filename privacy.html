Privacy Policy

Last updated: November 12, 2026

Clipper is a personal desktop tool used only by its owner. It has no server and no database outside the owner's computer.

Data accessed through TikTok

  • Basic profile (user.info.basic): open ID and display name, used only to confirm which account is connected.
  • Video upload (video.upload): used only to send the owner's own clips as drafts to their TikTok inbox.
  • The access and refresh tokens are stored in a local file on the owner's computer. They are never sent anywhere other than TikTok's own API.

What Clipper does not do

  • It does not collect, sell or share any personal data.
  • It does not access other users' data, messages, followers or analytics.
  • It does not use cookies, trackers or advertising.

Deletion

Deleting the local token file, or revoking Clipper in the TikTok app (Settings and privacy → Security → Manage app permissions), removes all access immediately.
